# Publish the site and add it to GitHub

## 1. Safety check before going live
- Run a security scan of the site and its database.
- If anything serious shows up, I'll tell you and ask whether to fix it first.

## 2. Publish
- Publish the site to its public web address.
- The site stays private in practice: every page still needs Google sign-in, and new people can only join through your invite link.
- After publishing, I'll share the address. You can rename it, or connect your own domain from Project settings, then Domains.

## 3. Add to GitHub (you do this part)
I can't connect GitHub for you. It takes about a minute:
1. Open Project settings, then Git (or the + menu next to the chat box, then Project, then GitHub).
2. Connect your GitHub account and pick where the repository should go.
3. Lovable creates a new private repository and keeps it in sync automatically from then on.

## Notes
- Google sign-in on the published address uses the same setup as the preview. I'll check that sign-in works there after publishing.
- Future changes go live only when you publish again. Database changes apply right away.
