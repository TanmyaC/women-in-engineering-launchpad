# Women In Engineering Launchpad

I have founded a women in engineering group. Now we have a lot of participants and I would live to build a web page for all our resources. The major themes are finding a job, interview prep (generic and for functions), mentorship booking, useful resources etc. I have some docs that I want to add that were summaries from some sessions. Lets start with these.
